Sell an NFT

Selling is two steps: escrow the token to the marketplace's own address, then create the listing. Marketplace address: loading…

Why two steps, and does "1." work for any collection?

The marketplace only ever holds tokens a seller explicitly escrows to it — it never has standing permission to move your tokens. Step 1 calls the token's own collection contract directly (here, the demo collection's own Transfer function); a different collection may name its transfer entrypoint differently, so step 1's button is wired to this demo collection specifically. Step 2 (List) is the same for every collection registered with the marketplace.

This marketplace trades any GRC721 collection whose owning realm registers an adapter satisfying gno.land/p/gnomarket/market.NFT — it never imports a specific collection's package. See that package's doc comment for the ~10-line adapter shape a collection author writes.
