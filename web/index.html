Selling is two steps: escrow the token to the marketplace's own address, then create the listing. Marketplace address: loading…

Why two steps, and does step 1 work for any collection?

The marketplace only ever holds tokens a seller explicitly escrows to it — it never has standing permission to move your tokens. Step 1 calls the token's own collection contract directly using the same entrypoint name (Transfer(cur realm, to address, tid string)) as this repo's demo collection — a different collection may name its transfer entrypoint differently, in which case use that collection's own interface (e.g. its gnoweb page) for step 1, then come back here for step 2. Step 2 (List) is the same for every collection registered with the marketplace. Looking for other collections to trade? See the Collections page — a collection only appears in the picker above once its own realm registers with this marketplace (see About, below).

About

Realm: · view on gnoweb

This marketplace trades any GRC721 collection whose owning realm registers an adapter satisfying gno.land/p/gnomarket/market.NFT — it never imports a specific collection's package. Registration is per-collection, done once by that collection's own author — after that, any current owner of any token in it (regardless of who minted it or when) can sell it here. See that package's doc comment for the ~10-line adapter shape a collection author writes.
